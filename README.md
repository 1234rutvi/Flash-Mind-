🧠 FlashMind Ultimate

FlashMind Ultimate is an AI-powered study assistant built using Python and Streamlit.
It transforms uploaded study materials into interactive flashcards, quizzes, summaries, AI tutoring, mind maps, and analytics dashboards.

The platform supports multiple document formats and provides a modern learning experience with flip-style flashcards and intelligent question answering.
